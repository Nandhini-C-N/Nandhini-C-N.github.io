Team project (3 members) · Python, Whisper, FastAPI, Git & GitHub

People often can't file a complaint because the portal isn't in their language. RaiseIt lets them speak it in their own language, turns it into English text, classifies it and routes it to the right department.

My part: the voice and language layer.

  • Built the speech-to-text and translation pipeline with OpenAI Whisper.
  • Found Whisper's translate task inaccurate on a Telugu test sentence, so split it into two steps: transcribe, then translate.
  • Tuned decoding settings and compared results with the original transcription.
  • Connected the pipeline to the team's classifier API and added a browser-based complaint recorder.
  • Merged the voice module into the team repository through a pull request.
